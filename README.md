# Study-Flow: A Smart Study Planner

![AI Study Planner Banner](https://img.shields.io/badge/AI-Study--Planner-blueviolet?style=for-the-badge)
> _Study Flow generates a smart, AI-crafted study schedule based on your availability and subject intensity._

---

## 🚀 Overview

**Study Flow** is an AI-powered study planner that tailors your schedule to maximize productivity and help you study smarter, not harder. By understanding your available time and how challenging your subjects are, Study Flow creates custom study plans that adapt to your needs.

---

## 🧠 Features

- **AI-Generated Schedules:** Get dynamic, personalized study plans.
- **Availability Detection:** Plans around your real schedule.
- **Subject Intensity Analysis:** Focuses efforts according to difficulty.
- **Easy Progress Tracking:** Check off completed sessions.
- **Modern UI:** Responsive interface made with TypeScript.

## 📦 Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/ruba73/Study-Flow-A-smart-study-planner.git
   cd Study-Flow-A-smart-study-planner
   ```

2. **Install Dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start the App**
   ```bash
   npm start
   # or
   yarn start
   ```

4. **Open in Browser**

   Visit: `http://localhost:3000`

---

## 💡 Usage

1. **Input Your Subjects**
   - List all the subjects/courses you want to study.
2. **Specify Your Availability**
   - Let the app know your free hours or unavailable slots.
3. **Set Subject Intensity**
   - Assign a difficulty/importance score to each course.
4. **Generate Your Plan**
   - Press "Generate" for a custom, AI-created schedule.
5. **Track Progress**
   - Use the dashboard to mark completed sessions and review your next tasks.
